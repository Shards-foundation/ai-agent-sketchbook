# AI Agent Skills Sketchbook

## Purpose
A structured sandbox where AI agents can plan, reason, prototype, validate, and operationalize work. Functions as a cognitive workspace, technical design notebook, operational log, and governance surface.

## 1. Cognitive Workspace

### Planning & Ideation
* Brainstorming scratchpad
* Task decomposition (hierarchical TODO trees)
* Hypothesis generation and evaluation
* Exploratory reasoning notes
* Assumption tracking
* Constraint mapping
* Alternative strategy comparison

### Thinking Modes
* Chain-of-thought summaries (sanitized)
* Reflective reasoning loops
* Counterfactual simulation
* Predictive modeling notes
* Failure-mode analysis

## 16. Example Workflow Template

1. Define objective
2. Decompose tasks
3. Identify tools/resources
4. Retrieve contextual knowledge
5. Plan execution DAG
6. Apply governance checks
7. Execute and log
8. Evaluate results
9. Store learnings
10. Iterate
